# Agent B v3.3.2

Local build notes. These changes are published in v3.3.4.

Chat replies now use a clean reading column with larger text, comfortable paragraph spacing and properly formatted Markdown. Headings, nested lists, emphasis, inline code, labelled code blocks, quotes, task lists and scrollable tables render directly in the conversation. Long answers remain visible in full instead of hiding behind a character-count disclosure. User messages stay in compact bubbles.

Formatting runs entirely locally with pinned, integrity-verified Marked and DOMPurify dependencies and their licenses. Raw HTML is displayed literally, unsafe links are removed, and external images become links rather than automatic downloads. Local attachment previews still display inline. Scope, approval, thinking and subagent controls remain available.
